# bluefin-vm

Turn the upstream **[Bluefin](https://projectbluefin.io)** bootc container into a running Linux VM on Apple Silicon with
one command.

The objective is to deliver a fast, low-friction dev environment — no ISO, no installer, no greeter

## Documentation

`bluefin-vm` installs from a Homebrew tap.

- [Getting started](https://bluefing.github.io/bluefin-vm/getting-started)
- [Installation](https://bluefing.github.io/bluefin-vm/getting-started/install/)
